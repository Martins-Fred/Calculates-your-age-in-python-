# Age Calculator

A simple Python script that calculates your age based on your birth year.

## Description

This program asks for your birth year and works out how old you are by
subtracting it from the current year (2026).

## Requirements

- Python 3.6 or higher (uses f-strings)

## Usage

1. Save the script as `age_calculator.py`.
2. Run it from your terminal:

   python age_calculator.py

3. Enter your birth year when prompted.

## Example

Enter your birth year: 2000
you are 26 years old.

## Notes

- The current year (2026) is hardcoded, so the script will need updating
  each year, or you can use `datetime.date.today().year` instead.
- Enter the year as a whole number (e.g. 1995). Letters or decimals
  will cause an error.
- The result may be off by one if your birthday hasn't happened yet this year.
